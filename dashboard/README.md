# لوحة ونش إنقاذ الإسماعيلية — PHP وSQLite

لوحة مستقلة عن موقع TanStack، بدون Composer أو قاعدة بيانات خارجية. تعمل على استضافة cPanel مع PHP 8.2+ وامتدادي PDO_SQLite وZipArchive.

## التثبيت على cPanel

1. أنشئ نطاقًا فرعيًا مثل `dashboard.ammar.company` واجعل مجلده جذر المستندات الخاص به.
2. ارفع محتويات هذا المجلد إلى جذر النطاق الفرعي، وفك ملف ZIP هناك.
3. من مدير الملفات اجعل `storage/` و`uploads/` قابلين للكتابة من PHP (عادةً 750 أو 755 حسب إعداد الاستضافة). لا تجعل مجلد `storage/` متاحًا للعامة.
4. افتح `/install` وأنشئ حساب المدير. كلمة المرور لا تقل عن 12 حرفًا؛ لا توجد بيانات دخول افتراضية.
5. بعد نجاح التثبيت، احتفظ بنسخة من ZIP في مكان آمن. لا تحذف ملف قاعدة البيانات يدويًا.

تتطلب النسخ الاحتياطية امتداد `zip`، وتتطلب الصور امتداد `fileinfo`. تأكد من تفعيل HTTPS للنطاق.

## الوظائف

- لوحة عربية RTL، حساب مدير ومستخدم محرر، وإدارة الخدمات ومناطق التغطية والمقالات (منشور/مسودة).
- تعديل بيانات الهاتف وواتساب واسم الموقع؛ الأرقام الافتراضية هي الرسمية التي زودنا بها صاحب الموقع.
- رفع JPG/PNG/WEBP/GIF بحد 5 ميجابايت مع فحص نوع الملف واسم عشوائي.
- نسخة ZIP تتضمن لقطة SQLite متسقة وملفات الصور.
- واجهة عامة للقراءة فقط: `GET /api/v1/content?type=service|coverage|post` و`GET /api/v1/settings`. المسودات لا تظهر.
- بيانات أولية للخدمات والمناطق والمقالات تُضاف عند التثبيت فقط.

## اختبار محلي اختياري

من جذر مجلد اللوحة: `php -S 127.0.0.1:8080 -t .` ثم افتح `http://127.0.0.1:8080/install`.

## ملاحظات الاستضافة

جرّب التثبيت والنسخ الاحتياطي على النطاق بعد رفع الملفات؛ سياسات الصلاحيات وامتدادات PHP تختلف بين شركات الاستضافة. احتفظ بالنسخ الاحتياطية خارج مجلد الموقع أيضًا.
